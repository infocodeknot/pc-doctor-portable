SECTION 4: ORIGINAL PROBLEMS & BUGS FIXED
============================================================

PROBLEM 1: Windows PowerShell Icon Showing
  - Issue: App showed Windows PowerShell icon in taskbar
  - Cause: Console apps inherit parent process icon
  - Fix: Set-ConsoleIcon function using WM_SETICON message
  - Now: PCDoctor.ico shows on title bar + taskbar

PROBLEM 2: WPF Theme Switcher Breaking
  - Issue: Theme switcher stopped working after first use
  - Cause: WPF freezes StaticResource brushes
  - Fix: TemplateBinding-only approach for all controls
  - Now: Theme switches smoothly, all controls update

PROBLEM 3: GUI Crash on Windows Update Check
  - Issue: GUI hung/froze when checking updates
  - Cause: [powershell]::Create() runspace already open
  - Fix: [runspacefactory]::CreateRunspace() with proper setup
  - Now: Update check runs in background, UI stays responsive

PROBLEM 4: Dashboard Gauges Showing 0%
  - Issue: RAM/Disk gauges always showed empty
  - Cause: EndInvoke returns PSDataCollection, not value
  - Fix: Access [0] index from EndInvoke result
  - Now: Gauges show real usage (RAM 59%, Disk 66%)

PROBLEM 5: Dashboard Content Clipped/Invisible
  - Issue: Bottom of dashboard cut off
  - Cause: StackPanel in fixed-height Border
  - Fix: Views wrapped in ScrollViewer
  - Now: All content scrollable, nothing clipped

PROBLEM 6: Console Menu Showing Duplicate Numbers
  - Issue: Compact mode showed [1] 1 Auto Mode
  - Cause: String included number, code added prefix
  - Fix: Removed prefix in compact mode
  - Now: Shows "1  Auto Mode (Recommended)"

PROBLEM 7: Cleanup Tests Failing
  - Issue: Pester tests failed with file lock errors
  - Cause: Tests opened same log files as logger
  - Fix: Tests use safe temp directories
  - Now: 47/47 tests pass

PROBLEM 8: Config.json BOM Character
  - Issue: Config file had unexpected BOM marker
  - Cause: Set-Content added UTF-8 BOM
  - Fix: Clean rewrite with proper encoding
  - Now: Config parses correctly

PROBLEM 9: Live Timer Not Updating
  - Issue: Dashboard stats showed stale data
  - Cause: No periodic refresh mechanism
  - Fix: LiveTimer with 5-second interval
  - Now: Stats update every 5 seconds

PROBLEM 10: Compact Menu Input Prompt
  - Issue: Compact mode used old ">" prompt
  - Cause: Prompt not updated for new style
  - Fix: Changed to "  > " with spaces
  - Now: Clean Fluent-style input prompt
